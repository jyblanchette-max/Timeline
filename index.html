Comment ajouter mes événements ?

Modifie rois.csv, puis clique sur Recharger les données. Pour ajouter un groupe, crée un CSV avec les mêmes colonnes et ajoute son identifiant, son nom et son fichier à la liste groupes de config.json. Les fichiers sont chargés ensemble ; les cases au-dessus de la frise permettent de choisir les groupes visibles.

Chaque entrée possède un id unique et stable. Colonnes essentielles : debut;fin;titre;categorie;description. Années négatives = avant notre ère ; aucune année zéro. Laisse la fin vide pour un événement ponctuel. Conserve les sources jw.org et les précisions des dates. Ne déduis pas la fin d’un règne de sa seule durée.

Le chargement automatique nécessite HTTP/HTTPS. En ouverture locale, sélectionne plusieurs fichiers avec Ouvrir des CSV. L’import remplace les données affichées ; il ne modifie pas les fichiers sur le serveur. L’export réunit tous les groupes chargés, même ceux masqués, dans un seul CSV.
